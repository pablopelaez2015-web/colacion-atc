    Ajustes

    Aeronave
    Se usa para marcar las transmisiones dirigidas a ti (completo o abreviado: Kilo Papa Papa Alfa / Papa Papa Alfa) y para cerrar la colación sugerida.
    Reconocimiento
    El reconocedor local de Safari solo escucha un idioma a la vez. En modo nube se detecta automáticamente.
    Nivel a partir del cual se considera que hay una transmisión. Con el cable de audio del casco, empieza en −45 dB y baja el valor si se pierden transmisiones; súbelo si el ruido de motor dispara grabaciones vacías. La barra de la cabecera se pone verde cuando se supera.
    Claves API (se guardan solo en este dispositivo)
    Si está vacía y el LLM está activado, se usa la clave de OpenAI (gpt-4o-mini).
    Probar sin radio
    Para captar al controlador el iPhone debe recibir el audio del intercom/radio (cable de grabación desde el casco o el panel, o un transmisor Bluetooth en la salida de audio). El Bluetooth del propio casco (Bose/Lightspeed) solo envía al teléfono tu micrófono, no la radio.
